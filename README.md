# Melody Analyzer for Jazz 🎷🎸

音声をリアルタイムで分析し、ジャズ理論に基づいた最適なスケールを提案するアプリケーションです。
ピアノ鍵盤で視覚化する汎用版と、ギタリスト向けに特化した指板表示版の2種類を同梱しています。

## ✨ 主な機能

- **音声分析**: WAVファイルの読み込み、またはマイクからのリアルタイム録音に対応。
- **ピッチ検出**: `librosa`を使用した高精度な音程抽出。
- **スケール提案**: 検出された音から、Altered, Combination of Diminished, Lydian Dominantなど、ジャズ特有のスケールを可能性の高い順にリストアップ。
- **度数表示 (Degree Analysis)**: 選択したスケールのルートから見た各音の役割（R, b9, #11, b7など）を瞬時に計算。
- **リスニング機能**: 提案されたスケールをアプリ上で自動演奏し、響きを確認可能。
- **選べるビジュアライザー**:
  - `jazz_scale_app.py`: 4オクターブのワイドなピアノ鍵盤表示。
  - `jazz_scale_app_guitar.py`: 0-12フレットのギター指板表示（表示範囲のカスタマイズ可能）。

## 🚀 セットアップ

### 1. 依存ライブラリのインストール

Pythonがインストールされている環境で、以下のコマンドを実行してください。

```bash
pip install librosa numpy pyaudio
```

### 2. アプリの起動


#### 🎹 ピアノ版（汎用）

```bash
python jazz_scale_app.py
```

#### 🎸 ギター版

```bash
python jazz_scale_app_guitar.py
```

## 🛠 使い方
#### 1. ルート音指定 (任意): 

特定のコード上で分析したい場合は、右上のドロップダウンからルート音（Key）を選択します。

#### 2. 音声入力:

「📂 開く」から既存のWAVファイルを選択。

「🔴 録音開始」を押して楽器を演奏し、「⬛ 停止」で自動分析。

#### 3. 分析結果の確認:

リストからスケールをクリックすると、ビジュアライザーに入力音とスケールの構成音が色分け表示されます。

🟢 緑: スケールに一致している入力音

🔴 赤: スケール外の入力音（アプローチノートなど）

🔵 水色: スケールに含まれるその他の音

#### 4. 試聴: 
「🔊 スケール試聴」ボタンで、そのスケールの響きを確認できます。

### 🔧 ギター版の特別機能
ギター版（jazz_scale_app_guitar.py）では、表示範囲 (Display Range) を設定できます。

「Start: 5」「End: 8」のように設定すると、そのフレット間にある入力音だけが指板に表示されます。

異弦同音があるギターにおいて、自分が実際に弾いているポジションに絞って分析結果を確認するのに役立ちます。
